# ⭕ Tic-Tac-Toe Game ❌

A modern and responsive **Tic-Tac-Toe Web Application** built using **HTML, CSS, and JavaScript**.  
This game supports both **2-Player Mode** and **Player vs Computer Mode** with a smart AI system.

---

## 📌 Project Overview

This project is a fully interactive Tic-Tac-Toe game designed with a modern UI and smooth gameplay experience.  
Users can either play with another player or challenge the computer AI.

---

## ✨ Features

- 👥 2-Player Mode
- 🤖 Play Against Computer
- 🧠 Smart AI Moves
- 🎨 Modern Responsive UI
- 📱 Mobile-Friendly Design
- 🔄 Restart/New Game Option
- 🏆 Winner Detection
- 🤝 Draw Detection
- ⚡ Smooth User Experience

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
